KIRA KIRA IMPROVEMENT PATCH
Version 1.1

An improvement patch for the English Standard Edition of Kira Kira.
Requires the English game. Not for Curtain Call or the Japanese edition.

WHAT CHANGES

- Corrects mistranslations, missing meaning, grammar, punctuation, and awkward
  English, checked against the original Japanese script.
- Keeps natural dialogue, character voices, jokes, and established localizations.
- Replaces the hard-to-read game font with a clearer bold font.
- Preserves the story, choices, and route logic.

INSTALL

1. Close the game and extract the whole ZIP outside your game folder.
2. Double-click Install.cmd.
3. Select the game folder containing BGI.exe.
4. Launch BGI.exe normally. The game now loads the improved font itself.

Already using version 1.0? Run this version's Install.cmd on the same folder
to upgrade. Your saves and original uninstall backups are preserved.

SAVES

Existing saves are left untouched. An original-version save successfully loaded
and continued in testing, but the line displayed immediately after loading was
incorrect or cut off. Advancing to the next page restored normal patched text.
Older backlog entries can also retain the old wording. Full compatibility with
every old save is not guaranteed.

For the cleanest experience, start a new game. To continue an old save, keep a
backup, advance past the loaded page, then save in a new slot. Do not overwrite
your only original save.

REMOVE THE PATCH

Run Uninstall.cmd and select the same game folder. It restores the files from
before installation and leaves your saves alone. Keep the
KiraKira_Improvement_Backup folder until you no longer need to uninstall.

NOTES

Wrapping, long passages, enlarged text, the backlog, and choice selection have
been checked. The game itself is not included. All original game rights remain with their
owners. Font details and licensing are in FONT_LICENSE.txt.
